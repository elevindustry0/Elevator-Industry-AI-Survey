GitHub Pages upload package

Files:
- index.html: Long-form supporting article with contextual link to the original FIELDBOSS article.
- robots.txt: Allows crawling and points to the sitemap.
- sitemap.xml: Sitemap for the published GitHub Pages home page.

IMPORTANT: Before or immediately after publishing, replace YOUR-USERNAME and YOUR-REPOSITORY in both robots.txt and sitemap.xml with your real GitHub username and repository name. Example URL format:
https://your-username.github.io/your-repository/

For a user/organization site repository named your-username.github.io, the URL format is usually:
https://your-username.github.io/

Publish with GitHub Pages from the repository Settings > Pages. Make sure index.html, robots.txt, and sitemap.xml are in the published root. A sitemap does not guarantee indexing or ranking.
